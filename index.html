# 1 コマンド = 1〜2 分

  1. 説明 何をするコマンドか、いつ使うかを読む
  2. 打ってみよう 案内どおりに試し打ち
  3. お題 自分で考えて解く。書き方は 1 通りでなくて OK

お題の中身(ファイル名や移動先)は、開くたびに変わります。

1日→3日→7日→14日→30日
